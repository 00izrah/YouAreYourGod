Background Music Folder:
========================
You can drop any MP3 song (e.g. Brent Faiyaz tracks) into this folder named as:
  track.mp3
or:
  brent-faiyaz.mp3

The gallery audio player will automatically detect and play your file when the SOUND toggle is clicked.
If no MP3 file is present, the gallery seamlessly generates a custom procedural Brent Faiyaz-style late-night neo-soul electric piano & sub-bass ambient soundtrack via Web Audio!
